# Fundamentos em Java ☕

Repositório com os exercícios que desenvolvi para construir uma base sólida em **Java**, como primeira etapa da minha trilha de estudos rumo ao desenvolvimento back-end com **Spring Boot**.

São **45 exercícios**, organizados em ordem crescente de dificuldade: da lógica de programação até sistemas completos com orientação a objetos, coleções e tratamento de exceções.

---

## 📚 Conteúdo

### Lógica de programação

| Pasta | Exercícios | Conceitos |
|---|---|---|
| `nivel_1` | 01 a 05 | Entrada com `Scanner`, variáveis, operadores, divisão inteira, `%` (resto) e cast |
| `nivel_2` | 06 a 10 | Condicionais (`if/else`, `switch`), operadores lógicos e testes de fronteira |
| `nivel_3` | 11 a 16 | Laços de repetição (`for`, `while`, `do-while`), acumuladores e contadores |
| `nivel_4` | 17 a 21 | Arrays: leitura, percurso, maior e menor, ordem inversa e busca com variável sinalizadora |

### Orientação a objetos (`POO`)

| Exercícios | Conceitos |
|---|---|
| 22 e 23 | Classes, objetos, atributos, métodos e a palavra-chave `this` |
| 24 | Construtores |
| 25 | Encapsulamento: `private`, getters e setters com validação |
| 26 e 27 | Herança (`extends`, `super`) e sobrescrita de métodos (`@Override`) |
| 28 | Polimorfismo |
| 29 a 32 | Classes e métodos abstratos |
| 33 a 35 | Interfaces e implementação de múltiplas interfaces |

### Coleções (`Colecoes`)

| Exercícios | Conceitos |
|---|---|
| 36 e 37 | `ArrayList` de `String` e `Integer`, loop for-each |
| 38 e 39 | `ArrayList` de objetos, busca por atributo e objetos com estado |
| 40 | Sistema com menu: cadastro, listagem, busca e remoção segura |

### Exceções e projetos integradores (`Excecoes`)

| Exercícios | Conceitos |
|---|---|
| 41 e 42 | Tratamento de exceções com `try/catch` (`InputMismatchException`, `ArithmeticException`) |
| 43 | Lançamento de exceções com `throw` e `IllegalArgumentException` para validar regras de negócio |
| 44 | **Integrador:** sistema de hotel com classe abstrata, herança, interface, polimorfismo e exceções |
| 45 | **Projeto final:** sistema de academia com menu, matrícula, listagem, busca, cancelamento e relatório, tratando todas as entradas inválidas |

Cada arquivo `Main` traz, no topo, um comentário com o enunciado do exercício e o conceito trabalhado.

## 🛠️ Tecnologias

- **Java** (JDK 26)
- **IntelliJ IDEA**
- **Git e GitHub**

---

## ▶️ Como executar

1. Clone o repositório:
```bash
   git clone https://github.com/bruno-cO70/Fundamentos-em-Java.git
```
2. Abra a pasta do projeto no **IntelliJ IDEA**.
3. Navegue até o exercício desejado dentro da pasta `src` e execute a classe que contém o método `main`.
